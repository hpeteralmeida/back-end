# Back-End Repository

This repository contains a collection of exercises, tests, and small projects developed during my back-end development studies.
The content comes from both structured courses and personal practice, and is not restricted to a single programming language or technology.

### Purpose

The objectives of this repository are:

  * To practice and strengthen programming fundamentals
  * To apply concepts learned in courses
  * To experiment with different tools and approaches
  * To document my learning progress over time

### Contents

You may find:

  * Course-based exercises
  * Personal experiments and tests
  * Small back-end focused projects
  * Repetitions of concepts for deeper understanding

### Technologies

This repository is not limited to a single stack. Technologies may include:

  * Python
  * Flask
  * SQL and relational databases
  * Other back-end tools and libraries as I continue learning

### Structure

The repository is organized by:

  * Course name
  * Topic
  * Type of exercise

Each directory may contain different types of files depending on the context.

### Disclaimer

This is a learning-focused repository:

  * Code may not always follow best practices
  * Some implementations may be experimental
  * The primary goal is learning, not production readiness

### Updates

This repository is continuously updated as new topics are studied and practiced.
